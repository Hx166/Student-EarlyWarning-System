# 每周开发计划（V0.1）

> 本文件为 V0.1 阶段（第一至第四周）的历史周计划。第六阶段（数据集与训练）的周计划见 `docs/2026-10-28起开发计划.md` 第五节。

## 项目目标

完成 V0.1 演示版本，实现：

- 摄像头实时采集
- MediaPipe 人脸关键点检测
- EAR 闭眼检测

- Fatigue 疲劳分析
- Engagement 课堂参与度分析
- SQLite 数据存储
- Flask 数据展示
- 基础可视化 Dashboard
