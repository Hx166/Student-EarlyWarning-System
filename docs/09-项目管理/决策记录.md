## D-001 类别 ID 与方向

- **决策**：模型类别 ID 严格等于 DAiSEE 原始 Engagement 等级，不做反向映射。

| DAiSEE Engagement | 模型类别 ID | 含义 |
|---|---|---|
| 0 | 0 | 最低参与度 |
| 1 | 1 | 较低参与度 |
| 2 | 2 | 较高参与度 |
| 3 | 3 | 最高参与度 |

- **约束**：禁止复用现有风险分类映射（`0 normal / 1 attention_down / 2 fatigue / 3 high_risk`）。Engagement 单独建立标签映射；现有风险预测模块不改动。
- **影响**：`XGBoostModel` 需支持注入独立 `label_mapping`；`PredictionLog.risk_label` 的语义在 F 阶段单独处理。
- **状态**：已确认。

## D-002 样本粒度

- **决策**：第一版以一个完整视频片段作为一条训练样本；先按视频聚合视觉特征，不把每秒记录当作独立样本。
- **理由**：视频级标签对应视频级样本；避免重叠窗口造成伪样本膨胀；降低提取与训练成本。
- **数量**：以实际统计为准，已核实为 9067 个视频、8571 条标签记录（其中 8570 条可关联视频；见文末核实依据）。
- **状态**：已确认（数量已核实）。

## D-003 特征集

- **决策**：第一版保留现有 11 个特征作为候选，但必须逐项做有效性检查。

```text
ear_mean, ear_std, blink_rate, perclos,
pitch_mean, yaw_mean, roll_mean,
fatigue_score, attention_score,
head_down_duration, face_lost_duration
```

- **检查项**：能否稳定提取；缺失率；恒定值；异常值；`fatigue_score` 与 `attention_score` 的计算规则；是否直接或间接使用目标标签。
- **规则输出不算自动无效**，但必须通过基线实验与消融比较确认是否带来真实增益。
- **剔除条件**：存在标签泄漏、训练与推理定义不一致、严重依赖人工规则。
- **禁止**：第一版不因追求复杂度随意增加特征。
- **现状证据**（`src/cv/emotion/engagement.py:40`、`src/cv/behavior/fatigue.py:47`）：
  - `attention_score = 0.35×眼部(1−PERCLOS) + 0.25×头姿 + 0.25×(100−fatigue_score) + 0.15×在场`；
  - `fatigue_score = 0.50×PERCLOS + 0.20×眨眼率 + 0.15×低头时长 + 0.15×打哈欠时长`；
  - 两者均为规则计算，未使用 DAiSEE 标签。
- **初步判断**：无直接标签泄漏；`attention_score` 是参与度的规则代理，需在 E 阶段用消融对照（含/不含 `fatigue_score`、`attention_score`）决定去留。
- **状态**：已确认（消融实验在 E 阶段执行）。

## D-004 Engagement Level 0 的处理

- **决策**：保留四分类，不合并类别。
- **理由**：保留原始标注含义；不擅自改变研究目标；便于展示四个等级。
- **执行**：先报告类别分布与各类别指标；若 Level 0 明显不足或无法识别，提交证据后再讨论加权或其他处理。不得仅凭不平衡合并 0/1。
- **数据事实**：Level 0 共 61 条（Train 34 / Validation 23 / Test 4）。
- **状态**：已确认。

## D-008 片段级聚合口径

- **决策**：聚合取 **A**：`FeatureBuilder(window_seconds=10)` 的最后一行（生产链路），B（全记录独立复算）只作诊断。
- **依据**：C 阶段 20 条中 18 条 A/B 完全一致；2 条 302/314 帧片段因多一条 StateRecord 出现差异（pitch 最大 0.47°、roll 0.43°、EAR 0.001）。在线 10 秒窗口只会产生 A 的形态，取 A 可保证训练与推理同源，少一个例外。
- **影响**：20 条验证特征需用 `--mode analyze` 重生成一次，不重跑视频；阶段 D 全量沿用 A。
- **状态**：已确认（2026-10-28）。

## D-012 V1 接受基线模型

- **决策**：接受阶段 E 的未加权主模型作为 V1 模型；不再为提升 Test accuracy 继续调参或扩特征。
- **依据**：Test accuracy 0.4944 = 多数类基线；macro-F1 0.165→0.258、weighted-F1 0.327→0.483、AUC 0.635；Level 0（n=4）不可识别。加权版 accuracy 更低，未保存。
- **后果**：F/G 按“基线模型”完成集成与演示，界面与报告中明确标注，不宣称高准确率；后续版本再改数据或特征。
- **状态**：已确认（2026-10-31）。

## D-013 V1 演示系统范围

- **决策**：V1 做成一个可独立启动、可现场演示的完整系统，三个页面：
  1. `/` 实时看板（摄像头、指标、模型卡片、图表、预警）；
  2. `/playback` 视频回放（选 DAiSEE 片段，服务端处理，逐秒曲线 + 片段级等级/概率 + 真实标签）；
  3. `/model` 模型说明（阶段 E 指标、标签映射、已知局限）。
- **兜底**：摄像头不可用时用回放页完成演示；模型缺失时页面显示“未就绪”，不崩溃。
- **不做**：视频上传、用户/权限、多页历史检索、深度模型。
- **状态**：已确认（2026-10-31）。
