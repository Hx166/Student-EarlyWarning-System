# 成员分工

本项目采用模块化协作方式开发，以下分工与 `README.md` 保持一致，并与五个开发阶段的职责对应。

| 成员 | 职责 | 对应模块 |
|------|------|----------|
| A | 项目管理、架构设计 | 项目框架、配置、日志、统一数据结构、main 启动流程 |
| B | 计算机视觉 | Camera 采集、CV 流程编排（CVProcessor） |
| C | MediaPipe、人脸检测 | FaceDetection、MediaPipe（Face Mesh 468 + Pose） |
| D | 疲劳检测 | EyeEAR、HeadPose、Fatigue |
| E | 课堂参与度分析 | Engagement |
| F | 数据库 | SQLite Schema、DatabaseService |
| G | 后端与可视化 | Flask API、Dashboard（ECharts） |
| H | 测试与质量保障 | pytest 测试、Bug 记录 |

---

## 第四阶段（机器学习）分工

第四阶段新增机器学习相关工作，由以下成员协作完成：

| 职责 | 对应模块 |
|------|----------|
| 特征工程 | Feature Engineering（src/models/features） |
| 模型训练与评估 | XGBoost（src/models/xgboost） |
| 模型管理 | Model Registry（src/models/registry） |
| 风险预测/推理 | Risk Prediction（src/models/risk_prediction） |

---

## 第五阶段（部署与优化）分工

第五阶段新增部署与优化相关工作，由以下成员协作完成：

| 职责 | 对应模块 |
|------|----------|
| 实时预测接线 | PredictionService、predict 蓝图（src/service/prediction、src/api/routes/predict） |
| 可解释性 | SHAP（src/models/shap） |
| 时序预测 | LSTM（src/models/lstm） |
| 数据库后端 | DatabaseBackend（src/database/backends）、InfluxDBWriter（src/database/timeseries） |
| 部署 | Dockerfile、docker-compose.yml、docs/07-部署/ |

---

## 说明

- 上述分工对应"五阶段已完成"的实际职责。
- ONNX/TensorRT 等模型量化优化、多摄像头同步、用户权限系统等属后续计划，待开发后再补充相应分工。
