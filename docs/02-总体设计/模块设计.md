# 模块设计

## 1. 模块划分

系统划分为以下模块：

| 模块 | 功能 |
|------|------|
| Camera | 摄像头采集 |
| CV | 人脸与姿态识别 |
| Behavior | 行为识别 |
| Database | 数据存储 |
| API | Web接口 |
| Dashboard | 可视化 |
| AI | 风险预测 |

---

## 2. Camera模块

负责：

- 摄像头连接
- 视频采集
- 帧读取
- FPS统计

输出：

```
Frame
```

---

## 3. CV模块

输入：

Frame

输出：

```
Face Landmark

Pose Landmark

Head Pose

EAR

MAR（已实现，第五阶段）

Gaze（未实现）
```

---

## 4. Behavior模块

根据视觉特征识别：

- 闭眼
- 打哈欠
- 低头
- 转头
- 离开

输出：

```
Student Status
```

> 注：行为事件（blink/head_down/yawn/looking_away/absent）已通过 BehaviorEventTracker 在运行时持久化至 BehaviorRecord（第五阶段）。

---

## 5. Database模块

保存：

- 学生信息
- 检测结果
- 历史记录
- 风险记录

---

XGBoost（已完成，第四阶段）
