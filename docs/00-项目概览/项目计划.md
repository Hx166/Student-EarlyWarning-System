# 项目计划

## 1. 项目周期

项目周期：

**2026 年 5 月 — 2027 年 4 月**

采用迭代开发方式，每个阶段形成一个可运行版本。

---

## 2. 阶段规划

### 第一阶段（项目框架）— ✅ 已完成

主要任务：

- 建立项目结构；
- 配置管理与日志系统；
- 完成摄像头采集；
- 集成 MediaPipe；
- 建立 SQLite 数据库；
- 搭建 Flask API 与 Dashboard 框架。

交付成果：项目可启动，`python src/main.py` 打通完整数据流。

---

### 第二阶段（计算机视觉）— ✅ 已完成

主要任务：

- Camera 采集；
- FaceDetection 人脸检测；
- MediaPipe 468 关键点 + Pose；
- EyeEAR（EAR/眨眼/PERCLOS）；
- HeadPose（Pitch/Yaw/Roll）。

交付成果：视觉数据实时产生。

---

### 第三阶段（课堂状态分析）— ✅ 已完成

主要任务：

- Fatigue 疲劳评分与等级；
- Engagement 参与度评分与等级；
- SQLite 数据持久化；
- Flask API；
- Dashboard 实时看板。

交付成果：系统具备完整演示能力。

---

### 第四阶段（机器学习）— ✅ 已完成

主要任务：

- Feature Engineering 特征工程；
- XGBoost 4 类状态分类模型；
- Model Management 模型管理；
- Risk Prediction 风险预测/推理。

交付成果：输入特征向量输出风险类别/概率/等级。

---

### 第五阶段（部署与优化）— ⏳ 待开发

主要任务：

- 实时预测接入在线预警链路；
- SHAP 可解释性、LSTM 时序分析；
- MySQL / InfluxDB；
- Docker 部署与性能优化。

---

## 3. 开发原则

项目遵循"先实现、后优化"的开发理念。

每完成一个阶段，都应具备完整的演示能力和可验证的功能，不依赖未完成模块即可运行，为后续功能扩展提供稳定基础。
