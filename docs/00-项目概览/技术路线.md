# 技术路线

## 1. 总体思路

本项目采用"数据采集 → 状态分析 → 数据存储 → 风险预测 → 可视化展示"的技术路线。

整个系统采用模块化开发方式，各模块独立开发、统一接口、逐步集成。

---

## 2. 系统流程

```text
摄像头
    │
    ▼
OpenCV 视频采集
    │
    ▼
MediaPipe 人脸与姿态识别
    │
    ▼
行为分析（闭眼、低头等）
    │
    ▼
状态评分（Fatigue / Engagement）
    │
    ▼
SQLite 数据存储
    │
    ▼
Flask Web 服务
    │
    ▼
ECharts 可视化展示
```

机器学习链路（第五阶段已接入运行时）：

```text
Feature Engineering
    │
    ▼
XGBoost
    │
    ▼
Risk Prediction
    │
    ▼
PredictionLog / WarningLog
```

## 4. 开发原则

- 优先实现可运行版本；
- 保持模块之间低耦合；
- 数据接口统一；
- 配置集中管理；
- 每个版本都有可演示成果。
