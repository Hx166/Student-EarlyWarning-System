# 技术路线

## 1. 总体思路

本项目采用"数据采集 → 状态分析 → 数据存储 → 风险预测 → 可视化展示"的技术路线。

整个系统采用模块化开发方式，各模块独立开发、统一接口、逐步集成。

---

## 2. 系统流程

```text
摄像头
    │
    ▼
OpenCV 视频采集
    │
    ▼
MediaPipe 人脸与姿态识别
    │
    ▼
行为分析（闭眼、低头、离开等）
    │
    ▼
状态评分
    │
    ▼
SQLite 数据存储
    │
    ▼
Flask Web 服务
    │
    ▼
ECharts 可视化展示
```

---

## 3. 技术栈

| 模块 | 技术 |
|------|------|
| 视频采集 | OpenCV |
| 人脸识别 | MediaPipe Face Mesh |
| 姿态识别 | MediaPipe Pose |
| 数据处理 | NumPy、Pandas |
| 数据库 | SQLite（前期） |
| Web | Flask |
| 可视化 | ECharts |
| 机器学习（后期） | XGBoost、LSTM |

---

## 4. 开发原则

- 优先实现可运行版本；
- 保持模块之间低耦合；
- 数据接口统一；
- 配置集中管理；
- 每个版本都有可演示成果。
