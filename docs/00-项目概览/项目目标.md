# 项目目标

## 1. 总体目标

开发一套基于计算机视觉的学生课堂状态分析系统，实现课堂视频采集、学生状态识别、数据存储和基础预警，为后续学业风险预测提供数据支撑。

项目采用渐进式开发模式，不追求一次完成全部功能，而是通过多个阶段逐步完善系统能力。

---

## 2. 五阶段目标

截至 2026-08-19，五个开发阶段已全部完成（详见 `docs/2026-08-01起开发计划.md` 与 `docs/2026-08-15起开发计划.md`）。

### 第一阶段（项目框架）

完成系统基础框架：

- 项目目录
- 配置管理（configs/*.yaml）
- 日志系统
- Camera 模块
- CV 模块接口
- Database 模块
- API 模块
- Dashboard 框架
- main 启动流程

交付成果：`python src/main.py` 可启动并打通完整数据流。

### 第二阶段（计算机视觉）

实现：

- Camera
- FaceDetection
- MediaPipe（468 关键点 + Pose）
- EyeEAR（EAR/眨眼/PERCLOS）
- HeadPose（Pitch/Yaw/Roll）

交付成果：视觉数据实时产生。

### 第三阶段（课堂状态分析）

实现：

- Fatigue 疲劳评分与等级
- Engagement 参与度评分与等级
- SQLite 数据持久化
- Flask API
- Dashboard 实时展示

交付成果：系统具备完整演示能力。

### 第四阶段（机器学习）

实现：

- Feature Engineering 特征工程
- XGBoost 模型
- Model Management 模型管理
- Risk Prediction 风险预测/推理

交付成果：输入特征向量即可输出风险类别/概率/等级。

### 第五阶段（部署与优化）

实现：

- 实时预测接入在线预警链路与预测 API
- SHAP 可解释性、LSTM 时序预测
- MAR / 打哈欠与行为事件持久化
- 数据库后端抽象（SQLite / MySQL，InfluxDB 预留）
- Docker 部署与性能优化（多人逐人分析、后端精确 FPS）

交付成果：系统可部署、可上线。

## 3. 后续目标（V1.1+）

- Pipeline 多线程/异步解耦
- SHAP 风险解释面板接入 Dashboard
- InfluxDB 真实时序写入
- 多学生持久化与逐人预警链路
- GPU 推理
- 多摄像头同步、用户权限系统、云服务器集群部署

---

## 4. 最终目标

形成一套具有完整功能的学生课堂状态分析系统，实现数据采集、状态分析、风险预测和结果展示的完整流程，为智慧教育研究提供实验平台。
