# 性能测试

## 1. 指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 处理帧率 FPS | ≥20 | 后端精确统计（`/api/metrics/fps`） |
| 单帧融合计算 | ≤2 ms | Fatigue/Engagement 加权融合 |
| 单次预测 | ≤100 ms | XGBoost / SHAP 单样本解释 |
| 单次预测解释 | ≤1 s | SHAP 局部解释 |

## 2. FPS 统计

后端在 `PipelineService` 中以 1 秒窗口统计处理帧数，暴露 `current_fps`，
通过 `GET /api/metrics/fps` 返回，Dashboard 直接消费（不再前端估算）。

## 3. 性能优化项

- 多人逐人分析：`CVProcessor` 对所有检测到的人脸逐人分析（`face_analyses`）；
- 状态型分析器按 `face_id` 惰性创建，避免多人状态互相污染；
- ECharts 本地化，消除 CDN 网络延迟；
- GPU 推理（可选，默认 CPU）：MediaPipe/XGBoost/LSTM 可配置启用。

## 4. 验证方式

```bash
# 后端 FPS
curl http://localhost:5000/api/metrics/fps
```

建议在真实摄像头环境测量端到端 FPS 与延迟，并记录内存占用。
