# 单元测试

## 1. 测试框架

使用 `pytest`（兼容 `unittest` 风格用例），测试位于 `tests/` 下，与 `src/` 目录一一对应。

## 2. 目录结构

```text
tests/
├── api/        # Flask 路由（health/state/warnings/predict/model）
├── camera/     # 摄像头采集
├── cv/         # 视觉模块（EAR/HeadPose/Fatigue/Engagement/MAR/打哈欠）
├── database/   # 数据库（表/查询/后端切换/预测记录）
├── integration/# 集成（main api-only）
├── model/      # 机器学习（特征工程/XGBoost/模型管理/风险预测/SHAP/LSTM）
├── service/    # 业务（pipeline/预测接线/行为事件/FPS）
└── conftest.py # 项目根目录注入 sys.path
```

## 3. 运行方式

```bash
# 全量
pytest

# 单模块
pytest tests/cv/test_eye_ear.py

# 指定用例
pytest tests/model/test_lstm.py::LSTMModelLogicTest::test_default_params
```

## 4. 覆盖率要求

- 新增功能必须提供对应 pytest；
- Bug 修复必须增加回归测试；
- 依赖缺失时使用 `skip`（如 cv2/mediapipe/torch），并注明原因。
