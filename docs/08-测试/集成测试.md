# 集成测试

## 1. 目标

验证各模块协同工作：Camera → CV → Database → API → Dashboard 全链路。

## 2. 现有集成用例

- `tests/integration/test_main_api_only.py`：`--api-only` 模式下启动 API，验证数据库注入与查询接口可用；
- `tests/api/test_predict.py`：预测接口与 `ModelRegistry`/`RiskPredictor` 的集成（注入桩模型）；
- `tests/service/test_pipeline_prediction.py`：Pipeline 接入预测（无模型降级、高风险触发预警）；
- `tests/service/test_pipeline_behavior.py`：Pipeline 行为事件写入 `BehaviorRecord`；
- `tests/service/test_behavior_tracker.py`：行为事件状态机（含 Pose 消费区分 absent / looking_away）。

## 3. 运行

```bash
pytest tests/integration tests/api tests/service -v
```

## 4. 联调方式

```bash
python src/main.py --api-only   # 仅 API，配合测试客户端
python src/main.py --frames 500 # 摄像头采集 500 帧后退出
```

## 5. 注意

- 集成测试尽量使用内存 SQLite（`:memory:`）与桩模型，避免依赖外部服务；
- MySQL / InfluxDB 为可选后端，其集成验证需自建服务（见 `docs/03-数据库/数据库迁移.md`）。
