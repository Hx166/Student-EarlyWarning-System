## 2. 方法与边界

- 扫描 `DataSet/{Train,Validation,Test}` 下的 `.avi` 和 `.mp4` 文件。
- 全量视频仅通过 `cv2.VideoCapture.get()` 读取 fps、宽高、帧数，并据此计算时长；未逐帧解码。
- 每个 split 使用固定种子 `42` 随机抽取 20 个视频，各实际调用一次 `read()`。
- 标签 CSV 所有列名执行 `strip()`，处理了末列实际的 `"Frustration "`。
- `ClipID` 去除首尾空格后与视频文件名（含扩展名）关联，不用数字前缀代替完整文件名。
- 未执行 MediaPipe、特征提取、训练、数据复制或原始数据写入。

脚本入口：

```powershell
python scripts/check_daisee.py --data-root "D:\数据集\DAiSEE\DAiSEE"
```

输入路径可由 `--data-root` 提供，或在 `configs/training.yaml` 中配置 `training.daisee_root`；输出目录沿用配置中的 `training.datasets_dir`。

## 9. 与 9068 的差异

实际目录包含 9067 个物理视频，另有 1 条标签记录 `2100552061.avi` 没有对应视频。将实际视频标识与标签标识取并集可得到 9068 个标识，但其中只有 9067 个物理视频。

因此：

- 9068 是“视频标识并集”，不是磁盘视频数；
- 9067 是 manifest 能覆盖的实际视频数；
- 8570 是具有可关联标签、可进入下一步特征提取的候选数；
- 1 条孤立标签无法训练，497 个无标签视频不能用于监督学习。
