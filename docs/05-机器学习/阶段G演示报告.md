## 1. 页面与接口

| 页面 | 地址 | 用途 |
|---|---|---|
| 实时看板 | `/` | 实时指标、规则预警、趋势图、模型参与度 |
| 视频回放 | `/playback` | DAiSEE 片段选择、处理、预测和曲线 |
| 模型说明 | `/model` | 模型指标、类别指标、混淆矩阵、消融和局限 |

| API | 说明 |
|---|---|
| `GET /api/demo/clips` | 返回 20 条固定演示片段 |
| `GET /api/demo/run/<clip_id>` | 完整处理一个片段并返回等级、概率和逐秒序列 |
| `GET /api/demo/video/<clip_id>` | 仅返回清单内 MP4 |

演示服务仅接受冻结清单中的 `clip_id`。视频路径从清单读取，并验证解析后的文件位于 DAiSE 数据根目录内，不使用 URL 拼接文件系统路径。

## 2. 页面实现

三页使用统一导航：

```text
实时看板 | 视频回放 | 模型说明
```

- 实时看板保留原有指标、预警、图表和表格；无数据时显示“等待画面”。
- 回放页从 `stage_c_sample.csv` 加载 20 条片段，展示真实等级、预测等级、置信度、四类概率和逐秒双线图。
- MP4 通过受控接口嵌入 `<video>`；浏览器无法播放时显示提示，曲线不受影响。
- 模型页从 `outputs/stage_e/metrics.json` 与模型元数据读取内容；缺失时显示“指标未生成”。
- 所有页面沿用本地 `echarts.min.js`，未引入 CDN。

## 7. 已知限制

- `engagement-v1` 是基线模型，Test accuracy 与多数类基线相等。
- Level 0 Test 样本只有 4 条，F1 为 0，不能声称模型能稳定识别最低参与度。
- 回放首次需要完整解码和 MediaPipe 处理，数秒级耗时属于预期；缓存只优化重复演示。
- AVI 不在浏览器内播放，仅展示预测与曲线；MP4 是否可播放还取决于浏览器编码支持。
- 模型概率未经外部校准，概率条只作辅助说明。
- 规则预警与模型等级并行存在，展示时不可把 `level_*` 解释为风险等级。
