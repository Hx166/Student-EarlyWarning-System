# 2. 目录规范

```text
datasets/
├── processed/
│   ├── daisee_manifest.csv         片段清单与元数据（脚本生成）
```

规则：

- 原始数据不进入仓库，也不写入 `D:\数据集\DAiSEE`；

- 路径写入 `configs/training.yaml`，脚本不硬编码；
- 每次生成覆盖同名文件，历史结果以 `docs/05-机器学习/DAiSEE训练评估.md` 的数据版本号区分。

# 3. 标签映射

类别 ID 严格等于 DAiSEE Engagement 等级（决策 D-001）：

| DAiSEE Engagement | 模型类别 ID | 含义 |
|---|---|---|
| 0 | 0 | 最低参与度 |
| 1 | 1 | 较低参与度 |
| 2 | 2 | 较高参与度 |
| 3 | 3 | 最高参与度 |

约束：

- Engagement 使用独立映射，**禁止复用**风险分类的 `LABEL_MAPPING`（`0 normal / 1 attention_down / 2 fatigue / 3 high_risk`）；
- 风险预测模块（`RiskPredictor`、`PredictionLog`、`/api/predict`）本版本不改语义；
- `boredom`、`confusion`、`frustration` 仅作元数据保留，不进入标签、不进入特征；
- 标签 CSV 列名带尾随空格（`Frustration `），读取时必须 `strip()`。

标签分布（实测 8571 条标签记录；可关联视频 8570，差值为 1 条孤立标签）：

| Engagement | Train | Validation | Test | 合计 |
|---|---|---|---|---|
| 0 | 34 | 23 | 4 | 61 |
| 1 | 213 | 143 | 84 | 440 |
| 2 | 2617 | 813 | 882 | 4312 |
| 3 | 2494 | 450 | 814 | 3758 |

Level 0 样本极少（Test 仅 4 条），指标不稳定属预期；处理方式见决策 D-004：保留四类、如实报告、不合并。

# 4. 数据集划分

1. 沿用官方 Train / Validation / Test（`DataSet/Train.txt`、`Validation.txt`、`Test.txt`）；
2. 已核实三集被试无交集（70 / 22 / 21 名被试）；
3. 不自行重划、不重排，保证与他人结果可比；
4. 训练只用 Train，调参与早停用 Validation，Test 只在最终评估使用一次；
5. 报告记录：三集片段数、被试数、四等级分布。

---

# 5. 样本与窗口

| 项 | 规则 |
|---|---|
| 样本单位 | 一个完整视频片段 = 一条样本（决策 D-002） |
| 片段时长 | 约 10 秒 |
| 片段内处理 | 按 1Hz 生成状态记录，再聚合为一行特征 |
| 聚合方式 | 取生产 10 秒窗口最后一行（A，D-008）；B 全记录复算仅作诊断 |
| 禁止 | 每秒一条样本、重叠窗口扩样、跨片段拼接 |

在线推理窗口与训练保持一致（10 秒），在 F 阶段修改 `configs/system.yaml`。

# 6. 清洗规则

| 问题 | 处置 |
|---|---|
| 无标签片段 | 不进入训练表，保留在 manifest 并记录 |
| 无法解码 / 损坏 | 剔除并记入 `daisee_issues.csv` |
| 标签越界（不在 0~3） | 剔除并记录 |
| 人脸检出率过低 | 设阈值剔除（C 阶段按 20 条样本实测后确定），记录比例 |
| 特征缺失 | 记录缺失率；单列缺失按 0 填充须在报告中说明 |
| 恒定列 | 记录；E 阶段判断是否剔除 |
| 数值异常 | 按训练集 0.5% / 99.5% 分位裁剪，边界写入训练配置 |
| 重复片段 | 按 `clip_id` 去重 |

清洗只作用于训练数据，不改动在线链路与原始文件。
