# 功能需求

## 1. 功能概述

本系统面向课堂教学场景，利用普通 USB 摄像头采集学生课堂视频，通过计算机视觉技术分析学生课堂状态，并将检测结果进行存储、统计和展示，为教师提供课堂状态分析依据，为后续学业预警模型提供数据支持。

系统采用模块化设计，各模块相互独立，可逐步扩展。

---

## 2. 功能模块

系统主要包含以下功能模块。

| 模块 | 功能描述 |
|------|----------|
| 视频采集 | 获取摄像头视频流，实时采集课堂画面 |
| 人脸检测 | 检测学生人脸并定位关键点 |
| 姿态识别 | 获取人体姿态及头部方向 |
| 行为识别 | 判断低头、闭眼、打哈欠、离开等行为 |
| 状态评分 | 根据视觉特征计算专注度 |
| 数据存储 | 保存检测结果及历史数据 |
| 数据查询 | 查询历史状态及统计信息 |
| 可视化展示 | 展示课堂整体状态及学生趋势图 |
| 风险预警 | 规则阈值预警 + XGBoost 风险预测（已接入运行时 Pipeline） |

---

## 3. 视频采集功能

系统应支持：

- USB 摄像头自动识别；
- 摄像头初始化；
- 实时视频采集；
- 视频帧缓存；
- 帧率统计；
- 摄像头异常提示。

---

## 4. 视觉分析功能

系统应支持：

- 实时检测学生面部；
- 提取 Face Mesh 468 个关键点；
- 获取人体 Pose 信息；
- 获取头部 Pitch、Yaw、Roll；
- 获取眼部关键点；
- 获取嘴部关键点；
- 获取视线方向。

---

## 5. 行为识别功能

系统至少应能够识别：

- 闭眼
- 长时间闭眼
- 打哈欠
- 低头
- 左右转头
- 身体离开画面

所有行为均应记录发生时间及持续时长。

---

## 6. 数据管理功能

系统应能够：

- 保存学生信息；
- 保存每次检测记录；
- 查询历史记录；
- 删除历史数据；
- 导出检测结果。

第一阶段采用 SQLite 数据库。

---

## 7. 数据展示功能

系统应提供：

- 当前课堂状态；
- 学生专注度；
- 行为统计；
- 历史趋势图；
- 风险学生列表（后续）。

---

## 8. 后续扩展功能

已实现（第五阶段）：

- XGBoost 风险预测接入实时 Pipeline/API
- SHAP 可解释性（模块完成，Dashboard 面板待后续）
- LSTM 时序分析

后续版本计划增加：

- 班级热力图
- 教师端 Web 平台
- 多摄像头支持
- GPU 推理
- 用户权限系统
