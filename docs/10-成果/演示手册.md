# 演示手册

> 适用范围：Student EarlyWarning System V1
>
> 模型：`engagement-v1`
>
> 页面：实时看板 / 视频回放 / 模型说明

---

## 1. 启动方式

在项目根目录执行：

```powershell
D:\Anaconda3\envs\Student-EarlyWarning-System\python.exe -m src.main
```

该命令启动摄像头、视觉分析、预测和 Flask 页面。停止时使用 `Ctrl+C`。

摄像头不可用或只演示已录制片段时：

```powershell
D:\Anaconda3\envs\Student-EarlyWarning-System\python.exe -m src.main --api-only
```

API-only 模式不会打开摄像头，但视频回放和模型说明页面仍可正常使用。

浏览器打开：

- 实时看板：<http://127.0.0.1:5000/>
- 视频回放：<http://127.0.0.1:5000/playback>
- 模型说明：<http://127.0.0.1:5000/model>

## 2. 页面说明

### 实时看板

- 顶部导航可切换三个页面。
- 页面显示 FPS、EAR、PERCLOS、头部姿态、疲劳与参与度。
- “模型参与度”展示 Engagement 等级、置信度、模型版本和四类概率。
- 无摄像头或没有状态数据时显示“等待画面”，已有规则预警和趋势图逻辑保持不变。
- 实时画面区域当前为占位；P1-01 完成后显示摄像头 MJPEG 画面。演示时口头说明“画面接入为下一版”，不影响指标与回放演示。

### 视频回放

- 下拉框列出 DAiSEE 阶段 C 的 20 条固定演示片段。
- 每条显示 `clip_id`、真实 Engagement 等级和帧数。
- 点击“运行回放”后完整处理片段，首次通常需要数秒。
- 结果包含真实等级、预测等级、置信度、四类概率和逐秒参与度/疲劳度曲线。
- MP4 片段会提供视频播放器；AVI 不内嵌播放。
- 同一片段再次运行使用服务端缓存，实测约 0.007 秒。

### 模型说明

- 显示模型版本、数据版本、训练样本数和 11 个特征。
- 显示 Engagement 四类映射。
- 对比 Validation/Test 的多数类基线与模型指标。
- 显示 Test 每类指标、混淆矩阵、消融结果和已知局限。
- 指标文件缺失时显示“指标未生成”，页面不会崩溃。

## 3. 三分钟演示脚本

### 0:00–0:40 正常状态

1. 打开实时看板。
2. 面向摄像头，保持正常坐姿并短暂注视屏幕。
3. 说明实时 EAR、PERCLOS、头部姿态和规则型参与度分数。
4. 指向“模型参与度”卡片，说明这是四分类模型输出，不是风险等级。

### 0:40–1:30 低头或闭眼

1. 缓慢低头数秒，再抬头恢复正常。
2. 可短暂闭眼，观察 PERCLOS、疲劳趋势和规则提示变化。
3. 说明规则预警与模型等级是两条并行信息，阈值语义没有混用。
4. 如果模型尚未累积满 10 秒记录，卡片保持“模型未就绪”或等待下一次刷新。

### 1:30–2:30 视频回放

1. 打开视频回放页。
2. 选择 `1100152070.avi`（真实 Level 0）。
3. 点击“运行回放”，说明首次需要完整解码和特征提取。
4. 展示真实/预测等级、四类概率和逐秒曲线。
5. 再次点击同一片段，说明结果由内存缓存返回。

### 2:30–3:00 模型局限

1. 打开模型说明页。
2. 展示 Test accuracy 与多数类基线相同。
3. 说明 Level 0 样本极少、F1 为 0。
4. 明确结论：“这是可运行的基线系统，不是高精度参与度诊断系统。”

## 4. 摄像头故障切换

若摄像头打不开、画面卡死或环境没有摄像头：

1. 停止当前进程。
2. 执行 `python -m src.main --api-only`。
3. 打开 `/playback` 直接演示 DAiSEE 已录制片段。
4. 打开 `/model` 说明模型指标与局限。
5. 实时看板仍可打开，并显示“等待画面”，不会白屏。

## 5. 推荐话术

- “Engagement 0–3 是 DAiSEE 参与度四级标签，不是学业风险等级。”
- “`risk_level` 是为了兼容旧接口保留的字段，在 Engagement 模式下值与 `level_*` 相同。”
- “当前模型 Test accuracy 与多数类基线持平，主要展示链路、特征和评估流程。”
- “概率条辅助理解模型输出，不代表经过校准的现实信心。”
- “Level 0 只有 4 条 Test 样本，因此不对该类稳定性作夸大结论。”
