# 安装说明

## 1. 环境要求

| 软件 | 版本 |
|------|------|
| Python | 3.11+ |
| pip | 最新稳定版 |
| 摄像头 | USB 摄像头或兼容设备（可选，api-only 模式可无） |

## 2. 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：`opencv-python`、`mediapipe==0.10.14`、`numpy`、`pandas`、`xgboost`、`scikit-learn`、`flask`、`pyyaml`、`pytest`、`matplotlib`、`shap`、`pymysql`、`torch`。

> 注：`torch`（LSTM）体积较大，CPU 环境可加速安装：
> `pip install torch --index-url https://download.pytorch.org/whl/cpu`

## 3. 启动系统

```bash
python src/main.py
```

启动参数：

```bash
python src/main.py --frames 1000   # 处理 1000 帧后退出
python src/main.py --api-only      # 仅启动 API，不采集摄像头
```

## 4. 访问

- Dashboard：`http://localhost:5000`
- 健康检查：`http://localhost:5000/api/health`

## 5. 运行测试

```bash
pytest
```
