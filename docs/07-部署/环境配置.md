# 环境配置

## 1. 运行环境

- Python 3.11+
- 依赖安装：`pip install -r requirements.txt`

## 2. 数据库后端配置

系统默认使用 SQLite，可通过 `configs/database.yaml` 切换后端：

```yaml
database:
  backend: "sqlite"   # sqlite（默认）| mysql
```

### MySQL（可选）

启用 MySQL 需安装驱动并创建目标库：

```bash
pip install pymysql
mysql -e "CREATE DATABASE early_warning CHARACTER SET utf8mb4;"
```

随后修改 `configs/database.yaml` 的 `mysql` 段（host/port/user/password/database），
并将 `database.backend` 设为 `mysql`。详见 `docs/03-数据库/数据库迁移.md`。

### InfluxDB（预留，默认关闭）

高频时序数据写入 InfluxDB 需安装客户端并开启开关：

```bash
pip install influxdb-client
```

在 `configs/database.yaml` 中配置 `influxdb`（url/token/org/bucket）并将 `enabled` 设为 `true`。
