# 项目目标

## 1. 总体目标

开发一套基于计算机视觉的学生课堂状态分析系统，实现课堂视频采集、学生状态识别、数据存储和基础预警，为后续学业风险预测提供数据支撑。

项目采用渐进式开发模式，不追求一次完成全部功能，而是通过多个版本逐步完善系统能力。

---

## 2. 第一阶段目标（V0.1）

完成系统基础框架，主要包括：

- 摄像头视频采集
- OpenCV 图像处理
- MediaPipe 人脸与姿态识别
- 基础行为检测
- SQLite 数据存储

交付成果：

- 能够实时检测学生状态
- 能够保存检测数据
- 能够稳定连续运行

---

## 3. 第二阶段目标（V0.2）

在第一阶段基础上继续完善：

- 行为识别优化
- 专注度评分
- SQLite 数据管理
- 基础可视化界面

---

## 4. 第三阶段目标（V0.3 及以后）

逐步加入：

- 特征工程
- XGBoost 风险预测
- Flask Web 服务
- ECharts 数据展示
- LSTM 时序分析
- 模型解释与系统部署

---

## 5. 最终目标

形成一套具有完整功能的学生课堂状态分析系统，实现数据采集、状态分析、风险预测和结果展示的完整流程，为智慧教育研究提供实验平台。
