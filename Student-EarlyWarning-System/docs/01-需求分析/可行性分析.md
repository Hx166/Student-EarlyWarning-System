# 可行性分析

## 1. 技术可行性

本项目主要采用 Python 技术栈，包括 OpenCV、MediaPipe、Flask、SQLite 等成熟开源框架。

上述技术均具有完善的文档和社区支持，能够满足课堂状态分析系统的开发需求。

对于后续风险预测，可逐步引入 XGBoost 和 LSTM 模型，不影响现阶段系统开发。

---

## 2. 经济可行性

系统开发所需软件均采用开源方案：

| 软件 | 费用 |
|------|------|
| Python | 免费 |
| OpenCV | 免费 |
| MediaPipe | 免费 |
| Flask | 免费 |
| SQLite | 免费 |

开发阶段仅需普通电脑和 USB 摄像头即可完成。

---

## 3. 开发可行性

项目采用模块化开发方式，各成员可分别负责视觉分析、数据库、后端、前端、机器学习等模块，降低协作复杂度。

每个版本均形成可运行成果，便于阶段性测试和验收。

---

## 4. 风险分析

目前主要风险包括：

| 风险 | 应对措施 |
|------|----------|
| 光照变化影响识别 | 增加图像预处理 |
| 遮挡导致关键点缺失 | 引入状态平滑机制 |
| 摄像头性能差 | 降低分辨率，提高帧率 |
| 数据不足 | 前期建立数据采集流程 |
| 模型效果不稳定 | 后续持续优化训练数据 |

---

## 5. 结论

综合分析，项目所采用的技术成熟、开发成本较低，具有较好的技术可行性和工程实现基础。项目采用“先实现基础功能，再逐步扩展智能分析能力”的路线，有助于降低开发风险，并保证各阶段均有可验证的成果。
