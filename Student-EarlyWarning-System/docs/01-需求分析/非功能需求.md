# 非功能需求

## 1. 性能需求

系统应满足以下性能要求：

| 指标 | 要求 |
|------|------|
| 视频帧率 | ≥20 FPS |
| 单帧处理时间 | ≤50 ms |
| 启动时间 | ≤10 s |
| 内存占用 | 尽量控制在 2 GB 以内 |

---

## 2. 稳定性需求

系统应能够：

- 长时间稳定运行；
- 摄像头断开后自动恢复；
- 数据库异常时保证数据完整；
- 程序异常记录日志。

---

## 3. 可维护性

项目采用模块化开发。

各模块之间保持低耦合。

统一接口。

统一配置。

统一日志。

---

## 4. 可扩展性

系统应支持：

- 更换视觉模型；
- 更换数据库；
- 新增行为识别；
- 新增预测模型；
- 新增前端页面。

---

## 5. 安全性

系统应：

- 不保存原始视频（可配置）；
- 数据库定期备份；
- 防止非法访问；
- 日志记录关键操作。

---

## 6. 易用性

系统应支持：

- 一键启动；
- 自动加载配置；
- 自动检测摄像头；
- 图形化展示检测结果。
