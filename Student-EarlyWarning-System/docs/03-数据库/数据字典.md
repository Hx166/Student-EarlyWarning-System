## StateRecord

| 字段              | 类型       | 说明           |
| --------------- | -------- | ------------ |
| state_id        | INTEGER  | 主键           |
| student_id      | INTEGER  | 学生ID         |
| session_id      | INTEGER  | 课堂ID         |
| record_time     | DATETIME | 统计时间         |
| avg_ear         | REAL     | 平均 EAR       |
| avg_mar         | REAL     | 平均 MAR       |
| avg_pitch       | REAL     | 平均 Pitch     |
| avg_yaw         | REAL     | 平均 Yaw       |
| avg_roll        | REAL     | 平均 Roll      |
| perclos         | REAL     | PERCLOS 疲劳指标 |
| attention_score | REAL     | 专注度评分        |
| fatigue_score   | REAL     | 疲劳评分         |
